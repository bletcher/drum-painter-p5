User Guide

🚀 Quick Start Guide

Drum Painter turns your MIDI drums into a generative art tool. Paint visual patterns by playing your drums!
⚠️ Desktop Only: This app requires a desktop computer with Chrome, Edge, or Opera browser. Mobile devices and Firefox/Safari are not supported (Web MIDI API required).

1️⃣ Connect Your MIDI Device

  • Plug in your MIDI drums/controller via USB
  • Click "Allow" when browser asks for MIDI permission
  • Check MIDI status indicator in Quick Settings panel shows connected

2️⃣ Map Your Drums

  • Click Customize Drums button
  • Click the 🎛 Learn button next to a drum
  • Hit that drum pad on your controller
  • Repeat for all drums you want to use

3️⃣ Start Playing!

  • Play your drums - each hit paints on the canvas
  • Try different paint modes - Choose Staff (time-based), Freeform (random), or Chronicle (point-based), then select a style/layout
  • Press SPACE to start/stop video recording
  • Press S to save an image
  • Press BACKSPACE to clear and start fresh
💡 Tip: Start with Freeform → Classic Pointillism mode and experiment with blend modes to see beautiful color interactions! Try Dendritic Spreading for river-like patterns, Lightning for electric discharge effects, or Chronicle → Fibonacci Spiral for geometric growth patterns.

📖 Complete User Guide

MIDI Setup

Direct Mode: Each drum is mapped to a specific MIDI note and device. Hit a pad → paint appears.
Bank Mode: Hit pads to select which drum, use faders to control that drum's parameters (Alesis workflow).

To switch modes, click MIDI Mapping and choose your control mode at the top.

Paint Modes

Two-Mode System: Choose mode type (Freeform or Timeline) with radio buttons, then select style/layout from dropdown.

Timeline Mode - Time-Based Layouts (Sync with Metronome):

  • Staff: Traditional horizontal DAW-style sequencer with musical grid. Eighth triplet subdivisions by default.
  • Spiral: Notes appear exactly where/when played along an expanding spiral. One rotation per measure.
  • Rings: Concentric circles with angular positioning. Angle corresponds to time like a clock face.
  • Petals: Organic flower curves where position corresponds to elapsed time. Creates visual rhythm record.
  • Polygon: Rotating geometric pattern where position along perimeter corresponds to time.

Timeline Mode - Point-Based Layouts (Paint Immediately):

  • Fibonacci: Golden ratio spiral emanating from center, expanding with each hit
  • Radial: 8-fold mirrored radial patterns, perfect for mandalas

Freeform Mode (Random Placement):

  • Classic Pointillism: Random placement, pointillist style. Supports all shapes.
  • Gravity Field: Falling dots with velocity-dependent drift and fading strokes. Complex shapes auto-convert to circles.
  • Organic Growth: Natural clustering around migrating seed points. Supports all shapes.
  • Dendritic Spreading: Realistic river drainage networks with hierarchical branching. Complex shapes auto-convert to circles.
  • Lightning: Cloud-to-ground electrical discharge with fractal branching. Complex shapes auto-convert to circles.

Blend Modes

Control how new paint combines with existing layers:

  • Normal: Standard opaque painting
  • Multiply: Darkens, like overlapping ink
  • Screen: Lightens, additive brightness
  • Overlay: Boosts contrast, vivid results
  • Dodge: Brightens highlights, glowing effect
  • Burn: Deepens shadows, dramatic darkening
  • Add: Additive light for bright glowing overlaps
  • Difference: Inverts colors for psychedelic effects

Drum Customization

Click Customize Drums to access per-drum settings:

  • Color: Base color for this drum (HSL or hex)
  • Size: Size multiplier (30% to 300%)
  • Opacity: Transparency (10% to 100%)
  • Shape: Brushstroke, Splatter, Ink Blot, Circle, Square, Triangle, Hexagon, Star, Diamond
  • Hue Variation: Directional color shift (0° to 60°) - harder hits shift more toward max with velocity scaling
  • Rotation: Angle of shapes (0-360°)
  • Stroke: Enable/disable outline with custom weight (1-10px) and color

Recording & Export

  • Video Recording: Press SPACE or click recording button. Choose quality first. Recordings appear in "Recent Recordings" list where you can download, merge with audio, or delete them.
  • Audio Merge: Click "Merge Audio" on any recording to upload an audio file (MP3, WAV, etc.). FFmpeg.wasm processes the merge entirely in your browser and downloads the combined MP4 automatically.
  • Image Save: Press S to save current canvas as PNG
  • Time-Based Recording: Press Start button to begin timeline. Check "Record video with timeline" to capture session. Staff and Spiral layouts require active recording.
  • Point-Based Layouts: Fibonacci, Radial, Rings, Petals, Polygon paint immediately without needing to start timeline - perfect for live performance and testing in debug panel.

Projects & Settings Export

Save Projects: Save complete configurations including drum settings, mappings, and visual preferences. Name your project, click Save, then load it anytime from the dropdown.

Export Settings: Click "Export Settings" to download a JSON file containing all your customizations. This file can be:

  • Shared with others
  • Used as a backup
  • Bundled with production builds (see Power User section)

⚡ Power User Guide

Device-Specific MIDI Mapping

Each drum can be mapped to a specific MIDI note + device combination. This prevents conflicts when multiple MIDI controllers send the same note numbers.

  • Exact Match: Drum only triggers from specific device + note
  • "Any Device" Mode: Clear device mapping to allow any source
  • Bank Mode Device Isolation: Pad and fader assignments are device-specific

Velocity Scaling Curves

Apply non-linear curves to how velocity affects size, opacity, and hue variation:

  • Fixed: Ignores velocity completely, always uses the slider value (constant size/opacity/hue)
  • 1:1: Direct linear response between velocity and value
  • Boost Soft: Amplifies soft hits using logarithmic scaling - more sensitivity at lower velocities
  • Gate Soft: Suppresses soft hits using exponential scaling - emphasizes harder hits
  • Gate Loud: Smooth quadratic suppression curve

Each drum can have independent curves for size, opacity, and hue variation. Use Fixed when you want consistent visuals regardless of how hard you hit the drum.

MIDI CC Live Control

Map MIDI faders/knobs to control parameters in real-time:

  • Per-Drum Mapping (Direct Mode): Each drum can have independent CC controls for size, opacity, hue, rotation, stroke
  • Global Mapping (Bank Mode): Faders control the currently selected drum's parameters
  • Auto-Calibration: Move controller through full range during 3-second learn period for accurate min/max detection
  • Pitch Bend Support: Pitch wheel mapped as pseudo-CC (1001-1016 for channels 1-16)

Time-Based Layouts (Rhythmic/Temporal Recording)

Staff mode has 5 time-based layouts (Staff Notation, Spiral Timeline, Rings, Petals, Polygon). All require pressing Start button, sync with metronome, and share these features:

  • BPM Sync: Grid aligns to beats per minute (40-240 BPM)
  • Time Signatures: Support for 2/4 through 12/4
  • Subdivisions: Quarter notes, eighth notes, triplets, sixteenths
  • MIDI Latency Compensation: Adjust 0-200ms to align visual to audio
  • Metronome: Audio click track with measure emphasis and visual spinning indicator
  • Video Recording Toggle: Check "Record video with timeline" to capture sessions to file, or uncheck for practice mode
  • Warmup Measures: 0-4 silent measures before painting begins

Staff Layout-Specific Settings

Staff Notation Layout:

  • Grid Toggle: Hide/show staff lines
  • Row Spacing: Adjust vertical spacing between drum lanes (0-50px)
  • Measures Per Staff: Auto or fixed number (1-8)

Spiral Timeline Layout:

  • Beat Synchronization: Rotation quantized to beat positions - completes one full rotation per measure
  • Tightness (5-40): Space between spiral rotations in pixels
  • Start Radius: Initial radius at center (adjustable)
  • Time Signature Matching: Automatically adjusts to match beatsPerMeasure (e.g., 4 positions in 4/4 time)

Chronicle Mode Advanced (Point-Based Sequential)

Timeline mode has 5 time-based layouts (Staff, Spiral, Rings, Petals, Polygon) that sync with the metronome, plus 2 point-based layouts (Fibonacci, Radial) where position depends on hit count.

Data Persistence & Auto-Save

All settings stored in browser localStorage with automatic saving:

  • Auto-Save: Settings automatically save 2 seconds after any change
  • Save Indicator: Dot next to MIDI status shows save state (yellow=pending, green=saved)
  • Manual Save: Press D for immediate save
  • Named Projects: Save multiple configurations
  • Bank Mode State: Pad/fader assignments persist
  • Drum Kit Config: Custom drum additions persist

Bundling Default Settings for Deployment

NEW FEATURE: Include your customized settings in production builds so they load automatically for all users:

  1. Configure all your settings (drum mappings, colors, sizes, etc.)
  2. Click "Export Settings" - a JSON file downloads
  3. Rename the file to default-settings.json
  4. Place it in the /public directory
  5. Run npm run build to include it in the build

How it works: App checks localStorage first, then falls back to default-settings.json if no saved settings exist. Perfect for deploying with pre-configured setups!

Debug Mode

Enable verbose console logging for development and troubleshooting:

  1. Open src/config/constants.js
  2. Change DEBUG_MODE from false to true
  3. Rebuild/refresh the app

Enables: Detailed console logging (211+ debug statements) showing MIDI events, mode switches, state changes, file operations. Errors and important status messages always shown regardless of DEBUG_MODE.

Production: Keep DEBUG_MODE = false (default) for cleaner console and better performance.

Browser & Device Requirements

Desktop Only: This app is designed for desktop computers with MIDI hardware. The app automatically detects and warns users on incompatible platforms:

  • Mobile Devices: Shows warning that desktop is required (phones/tablets cannot connect to MIDI hardware)
  • Unsupported Browsers: Firefox and Safari show MIDI compatibility warning with recommended browsers (Chrome, Edge, Opera)
  • Web MIDI API Required: Only Chromium-based browsers support the Web MIDI API needed for drum communication

You can still explore the UI with mouse/keyboard on incompatible setups, but MIDI functionality won't work.

🔧 Pro Tip: Export your setup to a JSON file and store it as a backup. For deployment, follow the steps above to bundle your customized defaults with the production build.
